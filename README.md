# Struct-to-Dict Python Program

## Project Description

This project demonstrates how student information can be stored in a Python dictionary and displayed on the screen.

The program stores the student's name, roll number, course, and branch as key-value pairs.

## Features

- Stores student information in a dictionary.
- Uses key-value pairs to organize data.
- Displays the dictionary using `print()`.
- Demonstrates basic Python dictionary concepts.

## Requirements

- Python 3.x

## Usage

1. Make sure Python 3 is installed.
2. Save the program as `struct-to-dict.py`.
3. Open a terminal in the folder containing the file.
4. Run the program using:

```bash
python struct-to-dict.py
```

## Example

```text
Student Dictionary:
{'name': 'Pihu', 'roll_no': 2571, 'course': 'B.Tech CSE', 'branch': 'AI & Data Science'}
```

## Notes

The program uses predefined student information. It does not ask the user to enter information.
